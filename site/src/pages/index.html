vb-project-planning

Web Components for the research, planning, and delivery phases of product work — personas, journeys, roadmaps, kanban, gantt and more, all themed by Vanilla Breeze.

Browse elements GitHub

Elements

  • <user-persona>

    Persona card.

  • <user-story>

    User story card.

  • <user-journey>

    Journey map with emotion curve.

  • <empathy-map>

    Says / thinks / does / feels.

  • <impact-effort>

    Impact vs. effort matrix.

  • <quadrant-grid>

    2×2 quadrant plotting surface.

  • <risk-register>

    Risk log with likelihood/impact.

  • <traceability-matrix>

    Requirement ↔ artifact grid.

  • <burndown-chart>

    Sprint/release burndown.

  • <product-roadmap>

    Time-phased roadmap.

  • <kanban-board>

    Kanban board (drag to reorder).

  • <story-map>

    User-story map.

  • <review-surface>

    Annotated review surface.

  • <gantt-chart>

    Gantt schedule.

  • <work-item>

    Work-item card.

  • <adr-wc>

    Architecture Decision Record.

Install

npm install @profpowell/vb-project-planning import '@profpowell/vb-project-planning'; import '@profpowell/vb-project-planning/css';

Pair with Vanilla Breeze tokens/themes — components inherit the active theme automatically (try the Theme picker above). The drag components (kanban-board, quadrant-grid, impact-effort, story-map) use VB's <drag-surface> peer.
