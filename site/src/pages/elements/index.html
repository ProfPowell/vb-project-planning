Elements

Sixteen project- and UX-planning components. Each page has a live, themeable example and its full API.

  • <user-persona>

    Persona card.

  • <user-story>

    User story card.

  • <user-journey>

    Journey map with emotion curve.

  • <empathy-map>

    Says / thinks / does / feels.

  • <impact-effort>

    Impact vs. effort matrix.

  • <quadrant-grid>

    2×2 quadrant plotting surface.

  • <risk-register>

    Risk log with likelihood/impact.

  • <traceability-matrix>

    Requirement ↔ artifact grid.

  • <burndown-chart>

    Sprint/release burndown.

  • <product-roadmap>

    Time-phased roadmap.

  • <kanban-board>

    Kanban board (drag to reorder).

  • <story-map>

    User-story map.

  • <review-surface>

    Annotated review surface.

  • <gantt-chart>

    Gantt schedule.

  • <work-item>

    Work-item card.

  • <adr-wc>

    Architecture Decision Record.
